# Change: Entity discovery and search

## Why

Users need to enter the historical network through people, places, texts, institutions, traditions, and events, using names across languages, scripts, and romanizations.

## What changes

- Add canonical entity pages for Person, Place, Institution, and Text, with shared source and relationship sections.
- Add PostgreSQL full-text search across entity types and multilingual alternate names.

## Non-goals

- No Elasticsearch, personalized recommendations, social profiles, or editorial publishing UI.
