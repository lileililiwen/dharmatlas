# Change: Open API and data export

## Why

The project's public-benefit goal includes allowing educators, researchers, visualizers, and other applications to use the dataset even if Dharmatlas itself is no longer hosted.

## What changes

- Add a versioned public read-only API for people, events, places, texts, and filtered relationships.
- Add documented bulk export with stable identifiers, source links, license metadata, and reproducible snapshots.

## Non-goals

- No write API, user authentication, billing, analytics platform, or unrestricted scraping guarantee.
