# Change: Historical data model

## Why

The atlas needs durable records for people, places, institutions, texts, traditions, events, names, relationships, sources, claims, and revisions before any UI can provide reliable historical exploration.

## What changes

- Define persistence and API contracts for the core entities and typed relationships.
- Add multilingual names, uncertainty-aware dates, historical certainty, source links, and revision provenance.

## Non-goals

- No UI, seed corpus, authentication, contribution workflow, or AI automation.
