# Change: Timeline exploration

## Why

Time is the first core entry point for understanding how Buddhist people, texts, places, institutions, traditions, and events developed together.

## What changes

- Add a 600 BCE–present timeline query and interactive view, initially focused on the MVP range 500 BCE–1000 CE.
- Support zoom levels, date overlap, category filters, region filters, and event detail links.

## Non-goals

- No map, graph visualization, editing, or unsourced event generation.
